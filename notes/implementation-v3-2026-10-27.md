### 架构与取舍

1. **Python 3.11+ / SQLite / 标准库核心**。SQLite 事务、唯一键和版本冲突检查承担原子性与去重，避免 JSONL 半行/双写。核心测试无需模型/API/网络。Windows 运行时安装与 ACL 必须真实验证，不能用本机结果替代。
2. **MCP 是窄适配层**。使用官方 Python SDK，固定经过测试的 v1 依赖；不手写协议。子进程启动时固定资料目录和身份，模型参数不含路径、其他孩子身份、父母工具或任意命令。先测真实 stdio 调用，再测试 WorkBuddy 能否加载。
3. **工具边界不等于操作系统沙箱**。同一用户的任意 shell/完全访问仍可能绕开工具。父母报告、另一孩子数据必须在不同 OS 权限空间；未验证前 W-B 不通过。
4. **最小记录与结构化父母摘要**。原始对话、图片、语音不进入工具数据库；父母摘要仅取经过校验的概念标签和行为枚举，不复制自由聊天/记忆正文/同伴姓名。自然语言教学质量由真实模型情境验收，不能用单元测试代替。
5. **更正/删除优先**。可选记忆内容实际清除，保留无原文撤回 ID。纠错撤回旧依据并生成新版本。旧备份恢复必须同时带当前删除清单，合并到现存状态，不覆盖更晚数据；新设备需成人提供来源端最新清单。无法证明“最新”的离线副本明确不保证恢复安全，不偷偷恢复。

```text
                                  │ 必要事实候选（可不记）
                                  v

```

### 测试图与失败处理

```text
输入候选
 ├─ 身份不符/归因不明/字段越界 → 明确拒绝，不写入 [核心测试]
 ├─ 同操作 ID 同内容 → 原收据；不同内容 → 冲突 [核心测试]
 ├─ 旧版本/同时写 → 冲突可重读，事务不半成品 [并发测试]
 ├─ 合法写入 → 收据 → 新进程读回 [持久化/CLI/MCP 集成]
 ├─ 纠错/忘记 → 实际内容清除 + 无正文撤回 ID [回归测试]
 └─ 恢复旧包 + 最新删除清单 → 不复活/不覆盖新状态 [恢复测试]

对话规则/材料
 ├─ 打包与目录分离 → 静态/包内容测试
 └─ 急求助、包办、阅读、危险出口等 T01–T42 → 成人真实模型评测

实际 WorkBuddy
 └─ G01–G10：账号、端、模式、加载、记忆、权限、媒体、恢复 → 实机证据
```

SQLite 繁忙、非法输入、损坏包、版本冲突均返回可识别错误；当前帮助可继续，不说“已保存”。配置/SDK/平台更新后重测对应路径。小型资料直接查询，无向量缓存、后台轮询、媒体转存或定时推送。
