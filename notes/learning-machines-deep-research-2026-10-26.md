# AI 学习机与学习工具深度调研（第一轮）

日期：2026-10-26。目的：学习成熟产品的交互逻辑与功能设计，反哺我们的学习助手。边界：**只研究、不推荐购买**；厂商与媒体宣称的数据未独立验证，本文逐一标注可信度；孩子信息未用于任何检索。

## 1. 市场格局与价格带

2026 年主流 AI 学习机价格带约 3,000–12,000 元：步步高 A7/S7（2,799–5,499）、学而思 P4/T4 Pro（3,499–7,299）、作业帮 T60/T70 系列（4,499–5,999）、小猿学练机 X9、科大讯飞 P30/S90 Pro（约 5,999）/T30 Pro（9,299–9,999）/T90 Pro/T30 Ultra（8,799–11,999）。学习机的商业本质是"硬件 + 内容订阅 + AI 服务"的打包，一次买断、无按次 API 成本——这与我们"网页版 + API 按量付费"的路线在成本模型上根本不同，也是学习机普遍敢做重功能（题库、诊断图谱）的原因。

## 2. 科大讯飞产品线拆解（重点样本）

讯飞是国内学习机份额领先者，产品线最完整，作为核心样本：

| 机型 | 价位 | 定位 | 与本项目相关的功能 |
| --- | --- | --- | --- |
| T90 Pro（2026 旗舰） | 8,000–9,000 档 | 全学段 | 步骤级诊断 + 跨年级知识溯源；超拟人 AI 老师"晓悦"启发式互动讲解；8 项护眼认证 + 坐姿监测 |
| T30 Pro | 9,299–9,999 | 全学段 | AI 1 对 1 精准学；星火 + DeepSeek 双引擎；同步 2026 春全国 32 套教材版本 |
| S90 Pro | 5,999 | 小学中年级 | 核心 AI 精准学与答疑辅导（与旗舰同引擎） |
| Lumie90 / T90 启蒙线 | 5,499 起 | 3–8 岁 | 熊小球语文、瑞恩熊英语、闪电鹿 AI 思维；IP 形象（玩具总动员联名） |

**核心交互闭环（官方描述的功能路径）**：
拍题/指题 → 识别 → **学情诊断**（定位到知识点，T90 Pro 可跨年级追溯前置知识）→ **路径规划**（个性化复习图谱、推送匹配难度的变式题）→ **微讲解**（启发式引导 + AI 板书 + 错因讲解）→ **变式练习** → **掌握度可视化**（知识图谱上色）→ **家长端报告**。媒体评测称其为唯一实现"学情诊断—路径规划—动态干预"闭环的学习机（搜狐测评，2026-10；媒体宣称，未独立验证）。

## 3. 可借鉴的交互逻辑（按我们的理念筛选）

1. **步骤级诊断**：不是"这题不会"，而是"卡在哪一步、缺哪个前置知识"。这与我们"从孩子的过程判断卡点"完全一致，且提示我们应要求**孩子先展示已有过程**（拍照含草稿）。
2. **掌握度图谱上色**：孩子能直观看到"这一单元从红变黄变绿"。对应我们"孩子看得见自己的进步"，可简化为"我的进步墙"（不需要知识图谱工程，用学习事件的 mastery 状态即可）。
3. **变式练习推送**：同技能换数字换情境。对应我们的"隔天迁移验证"，学习机的做法是即时推题，我们保持延迟（隔天），但可借鉴"变化题由助手出、不由孩子找"。
4. **超拟人老师"晓悦"**：拟人化 + 启发式讲解的组合是旗舰级产品的共同方向，验证了你"拟人化形象"的直觉。
5. **错因讲解而非答案讲解**：讲"为什么错"而不只是"正确怎么做"。与我们的规则一致。
6. **家长端只做摘要**：掌握度、待巩固点、建议动作——粒度与我们周报设计相当，证明这个粒度是行业验证过的。

## 4. 与我们理念冲突、明确不借的做法

1. **诊断标签化**：知识图谱直接输出"薄弱点"，容易滑向给孩子贴能力标签。我们保持"待验证假设"口径，掌握状态只有四档且需独立迁移验证。
2. **刷题导向的闭环**：学习机的变现依赖"多练"，路径规划终点是更多题。我们的终点是**不再需要助手**（逐步撤帮助）。
3. **即时给完整讲解的默认**：学习机答疑偏"讲透"，孩子容易先看讲解再想。我们坚持"先一个动作，讲透是后面级别"。
4. **营销话术**：提分率、准确率、使用时长统计——一律不作为我们的成效指标，也不进入家长报告。

## 5. 其他品牌一句话定位

- **学而思**：强在自研课程体系与培优内容，学习机=课程载体；逻辑是"内容变现"。
- **作业帮/小猿**：强在题库与搜题基因，"刷题+答疑"效率优先。
- **步步高**：渠道与家教机存量，AI 能力跟进中。
- 对我们的启发：内容体系（学而思）和题库（作业帮）都是重资产，我们不建；我们的差异化资产是**家庭价值观 + 两个孩子的个性化档案 + 引导式教学法**。

## 6. 实机体验清单（建议家长到店体验时带着看）

- [ ] 拍一道孩子的真实数学题，观察：识别结果是否给孩子确认？第一步给的是提示还是讲解？
- [ ] 连续答错两次，观察：是继续追问还是换讲法/降级？
- [ ] 问"直接告诉我答案"，观察产品的应对话术。
- [ ] 看家长端报告：粒度、有没有人格/态度类输出。
- [ ] 问店员：知识点诊断错误的更正路径（孩子纠正后系统是否更新判断）。
- [ ] 护眼与坐姿监测的实现方式（为我们以后选平板/电脑使用时长管理做参考）。
