## 0. 这份文档怎么来的

本轮赛马的两份产出：

- **Codex v2**：`notes/rebuild-v2/` 全套（PROPOSAL / TECH-ROUTE / KIMI-REVIEW / REVIEWS / DEVELOPMENT-HANDOFF / research/）。基础是五门课 113 份转录全文通读（约 65 万字）+ 模拟孩子视角与产品经理视角两轮审视（19 项修改）。Codex 的 v2 本身就是对 Kimi v1 的审视稿。
- **Kimi v2**：同一晚基于家长书架实拍建成的 `library/` 资产——147 条书目库（bk-0001~0039 孩子书架 + bk-0100~0207 家长藏书）与 `library/reading-cards/` 引读卡片库（tier1 现阶段 24 本逐本卡片 + tier2 远期灯塔备忘）。

两者高度同源，分歧不在方向上，而在**内容来源纪律**与**指标口径**两处。本文件取并集、裁决分歧，作为后续功能讨论的统一底稿；与 [PROPOSAL.md](PROPOSAL.md) 不一致处以本文件为准，实施前仍需家长逐项确认。

## 1. 双方一致，直接定稿的部分

以下在 Codex v2 与 Kimi 立场中无实质分歧，按 Codex v2 现行文本为准：

1. **定位**：平等伙伴——能求助、能讨论、一起读书和创造的 AI；不靠夸赞讨好，不每次变教学提问；不假装有真实生活经历；允许孩子不同意、纠正、拒绝。
2. **技术路线**：WorkBuddy 双独立账号（沫沫/一一各一）先行；网页/独立客户端为备用迁移路线；拍题与语音输入是首批验收项；**不做**口语跟读、发音评分、整页作业检查。
3. **四种意图一张表**：作业卡点 / 陪我读一会儿 / 我想做点东西 / 就想聊聊，同一伙伴按当前意图响应，不设固定冷启动剧本。
4. **帮助优先**：孩子说"你教我"就立即升级帮助，可直接示范当前关键步骤并解释；不代做的判定看**整段对话**是否包办了关键推理，而不是机械遮答案。
5. **作业期间伙伴主动收敛**：不主动聊猫小九剧情、荐书、创作邀约；孩子自己跑题时由她选择"记下以后聊"或明确切换；工具不能把作业延误全归给孩子。
6. **阅读**：先把书打开、容易退出；书架分两层（家庭持有 / 个人状态）；"没兴趣了"是完整选择；买后跟进默认关闭、由孩子对单本书自选开启一次；不以购书、完读、成人书级别为目标。
7. **证据而非性格**：周报只答"卡在哪/试过什么/什么帮助有效/能否独立继续"；无证据如实写不足；AI 讲错要撤回相关学情判断并提供报告更正版；自然语言"忘掉"即触发删除。
8. **首期范围**：三层交付表（必须可用/可人工维持/以后自动化）保持不变；成人先验收、孩子再试用；六 Skill 是能力划分不是一次建六套。

## 2. 分歧与裁决

### 2.1 引读卡片库的内容来源纪律（核心分歧）

- **Codex 立场**：书脊元数据 ≠ 读过书内内容；伙伴不能"凭书脊声称读过"；`interest_hook` 不能自动成为运行指令。
- **Kimi 立场**：卡片库按"对书的既有了解"编写，且区分了"孩子可直接读"与"伙伴转述素材"，但卡片本身没有内容来源标注。
- **裁决：卡片保留，引入三级来源标注制度。**

| 级别 | 含义 | 使用权限 |
|---|---|---|
| A 已读原文 | 对全书或目标章节有实际文本依据（家长藏书已上传的、伙伴通读过的） | 可转述具体情节、引原文、讨论细节 |
| B 既有知识 | 基于模型对公认名著/经典的稳定知识（小王子、费曼、费马大定理、人类简史等） | 可讲大意与公开著名桥段；**不得虚构具体页码、具体原文句子** |
| C 仅元数据 | 只有书名/作者/书脊信息 | 只可介绍主题方向，可说"我不确定这本的细节，要不要翻一页给我看看" |

执行规则：①每张卡片头部标注级别；②作业期间一律不引用卡片（与§1.5一致）；③孩子追问细节超出级别时，如实降级说明；④家长可抽查卡片，抽查发现的错误按 AI 纠错机制更正并记录。卡片话术本质是"候选引法"，触发仍需场景判断（先回应孩子当下话题）。

### 2.2 interest_hook 与画像

- **裁决**：147 条中的 `interest_hook` 降级为**候选假设**，孩子确认前不进入个人记忆、不生成推荐；家长描述的兴趣一律标 `parent_reported`。书架迁移按 TECH-ROUTE §5 的版本化规则执行，初始化 `unread` 不构成"未读债"。

### 2.3 成效指标

- **裁决**：以 Codex 口径为准——观察"愿意尝试/接续/理解/主动修改或反驳"的具体事例，不用 7 日回访率、购书数、完读数、纯文字比例等百分比或小样本统计。保留 Kimi 周报的**四问结构**（卡点/尝试/有效帮助/能否独立继续）与"孩子愿意分享的阅读/作品动态"一节，动态没有就如实不填。

### 2.4 创造场景

- 以 Codex §8 的"学科意义实际用一次"三学科表格（漫画对白/运动计分规则/双语介绍卡）为底，吸收 Kimi 的表述：知识是"发动机与工具"，游戏感来自孩子能选目标、试规则、看到变化、自己修改。这些是探索时间的可选邀请，不在作业后自动追加，不按姐妹固定分配。

### 2.5 买书闭环

- 以 Codex §7.5 为准：愿望单与到货状态分开；豆瓣评分（家长偏好）记录评分/人数/版本/查询日期/链接，无法访问标"未查"、不编数字；跟进默认关闭、单书自选一次；家长自购不自动成为孩子的阅读愿望，周报不列"已买未读欠账"。Kimi 卡片库中"买书闭环功能"相关话术按此口径改写后可用。

3. **五门课提炼**（新父母大学108讲、人是如何学习的、积极心理、亲子沟通、自主学习）：作为伙伴的**方法论底座**保留，转述级使用——课程作者的经验与数字不是系统规则，重要观点须能定位原文件；教育方法的引用"轻量、自然、可被拒"，不设普适数字门槛（此点 Codex v2 同）。
4. **伙伴体系 22 条 / 五入口结构**：不进入融合定稿；其中"作业救急顺手引数学史""教材配套=天然购书位"等钩子按 §2.2 与 §2.5 降级为候选假设。
