## 0. 一句话结论

**够用来做「诊断和卡点定位」，不够用来做「日常练习」。**
知识图谱与先修链的质量超出预期，可以直接当定位引擎；但每题 4 道题的量只够诊断，撑不住连续练习。

## 3. 关键能力验证：先修链回溯

这是本数据集对本方案最有价值的部分。实测回溯「五年级·异分母分数加减」：

```
异分母分数加减 (g5)
├─ 通分 (g5)
│  ├─ 分数的基本性质 (g5)
│  │  ├─ 分数的意义 (g5)
│  │  │  ├─ 认识几分之一 (g3)  ← 回溯到三年级
│  │  │  │  └─ 除法的意义 (g2)
│  │  │  │     ├─ 乘法的初步认识 (g2)
│  │  │  │     └─ 平均分（包含/等分）(g2)
│  │  │  └─ 认识二分之一 (g3)
│  │  └─ 因数和倍数 (g5)
│  │     └─ 除数是两位数的除法 (g4)
│  ├─ 商不变的规律 (g4)
│  └─ 最小公倍数 (g5)
│     ├─ 3的倍数的特征 (g5)
│     └─ 2和5的倍数的特征 (g5)
└─ 同分母分数加减 (g5)
   └─ 约分 (g5)
      └─ 最大公因数 (g5)
         └─ 质数和合数 (g5)
```

**结论：这个能力可以直接用。** 五年级孩子「异分母分数加减」反复错，系统能沿边一路查到是二年级「除法的意义」还是三年级「认识几分之一」没打牢——这正是本方案 §7.1「先区分问题性质」缺的定位引擎。

## 4. 数据质量评估

### 4.1 好的部分

| 字段 | 实测样例 | 对本方案的价值 |
| --- | --- | --- |
| `mastery_criteria` | 每条 2–3 条可观察标准，如「能说出分母表示平均分成了几份」 | 直接填 `independence_evidence`，不用自己定义「什么算会了」 |
| `verify` | `gcd(12,18)`、`3+1` | **可执行验证式**，机器判对错，不靠模型自评 |
| `diagnostic_question` | 每知识点自带诊断题 | 进场景前先探底 |
| `dependencies.strength` | hard / soft 两级 | 决定回溯时哪些是必查、哪些是参考 |
| `type` | conceptual / procedural / reasoning / application / modeling | 决定该讲还是该练 |

样例（五年级·最大公因数）：

```json
{"id":"cnm_p158","name":"最大公因数","domain":"数与代数","grade":5,"semester":"下",
 "type":"procedural",
 "mastery_criteria":["能找出两个数全部公因数","能说出最大公因数"]}
```

### 4.2 不足的部分（必须如实记）

| 问题 | 实测 | 影响 |
| --- | --- | --- |
| **题量太薄** | 每知识点固定 4 题 | 三年级数学仅 204 题，每天 20 题只够 10 天。**只能诊断，不能日常练习** |
| **同质化明显** | 最大公因数 4 题全是「X 和 Y 的最大公因数是多少」，只换数字 | 是刷题，不是理解 |
| **无过程性作答** | 题型只有 choice / numeric | 你 §5.1 的 `performance: partial`（部分对）**观察不到**，只能对/错二元 |
| **解析是单句** | 「公有因数里最大的是 4。」 | 不是提示阶梯。§7.2 的可跳级帮助需要自己按 hint pathway 重做分层 |
| **应用题占比中等** | 三数 51%、五数 56%（按情境关键词判） | 够做口头应用题，但不足以覆盖复杂题型 |
| **英语教材版本不一致** | 五上「Different friends」= 新版；五下「My day」= 旧版 | 需要按孩子实际课本核对 |

## 5. 覆盖度判定

| 用途 | 够不够 | 说明 |
| --- | --- | --- |
| 知识点定位 / 卡点诊断 | ✅ **够** | 图谱完整、先修链可回溯 |
| 客观判定对错 | ✅ **够** | `verify` 可执行 |
| 掌握度判定口径 | ✅ **够** | `mastery_criteria` 可直接用 |
| 教材单元对齐 | ⚠️ **需核对** | 结构像 2022 课标新版，但英语五上/五下版本不一致 |
| 日常练习巩固 | ❌ **不够** | 每知识点 4 题 |
| 复杂应用题 / 过程题 | ❌ **不够** | 只有 choice / numeric |
| 分层提示素材 | ⚠️ **要重做** | `explanation` 是答案理由，不是提示阶梯 |

## 6. 建议怎么用

1. **当定位引擎用，不当练习册用。** 用 `topics` + `dependencies` + `diagnostic_question` 定位卡点，这是它的强项。
2. **练习量另找来源。** 需要日常练习时，用 OATutor 的 hint pathway 结构 + 自己的题目来源；或按 `topicId` 组织孩子学校作业的错题。
3. **`explanation` 要包装成提示阶梯。** 它是「答案为什么是这样」，不是「你该怎么想」。需要自己按 L1 问卡在哪 / L2 给方向 / L3 给半成品 重做一层。
4. **先核对教材版本。** 拿一一（三年级）和沫沫（五年级）的实际课本目录，逐单元比对第 2.2、2.3 节清单，确认没有版本错位再接入。
5. **抽样复核题目。** 作者自述为 AI 生成初稿，建议每单元抽 5 道人工验算，重点看 `verify` 表达式是否与 `answer` 一致。

## 7. 复现方式

```bash
mkdir -p /tmp/cnm && cd /tmp/cnm
for f in topics dependencies cn-curriculum-standards questions; do
  curl -sL "https://raw.githubusercontent.com/xiaoyang111222/cn-math-taxonomy/main/data/$f.json" -o $f.json
done
```

数据结构：`topics` / `questions` / `dependencies` 均为 JSON 数组，`cn-curriculum-standards` 为按学科分键的对象。
