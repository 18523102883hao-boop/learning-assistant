# 引读卡片 · 使用说明

> 目的：伙伴（以及家长）在真实对话中"润物细无声"地引书。每张卡片回答三件事：**这本书到底讲了什么**、**孩子这个年龄能听懂的一句话版本**、**什么时候、怎么开口**。
>
> 编写原则（2026-10-26 家长要求）：
> 1. 只写有把握的内容——卡片基于对原书的真实了解编写；没把握的细节宁可不写，也不编。
> 2. 话术按沫沫（五年级，10–11 岁）和一一（三年级，8–9 岁）的理解力写，不是书的简介的缩写。
> 3. 引书的时机是"话题刚好走到这里"，不是任务式的推荐。孩子不接就放下，下次再来。
> 4. 所有卡片都是**转述素材**，不是让孩子必须读的书单。

## 文件

- [tier1-now.md](tier1-now.md) — 现阶段（小学～未来两年内）可以自然引的书，逐本详细卡片
- [tier2-later.md](tier2-later.md) — 初中以上的远期灯塔，每本一段"到时候怎么引"的备忘

## 与 bookshelf.json 的关系

卡片覆盖其中一部分重点书（bk- 编号可在卡片标题后查到）。其余成人书暂不需要卡片——它们是家长自读或伙伴远期素材库。
