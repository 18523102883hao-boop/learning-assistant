# 147 本书目知识库

> 用途：让阅读伙伴先确认“家里有什么”，再决定“这本书讲什么、什么时候可以轻轻提一句、哪些细节不能说”。它不替代孩子自己的阅读，也不把 147 个目录条目当作 147 本都已读完的书。

## 先分清三层

1. **家中有什么**：`library/bookshelf.json`。保留书脊识别、版本、合集/系列、目录备注与家长候选假设。
2. **书本身讲什么**：本目录的 `catalog.json`／`catalog.jsonl` 与 `browse/`。只写到可公开转述的大意，不伪造页码、原句或阅读经历。
3. **谁在读、读到哪、想不想买**：未来另存个人阅读状态；本目录不写，也不把初始化 `unread` 或 `owner` 当事实。

## 文件

- `data/*.tsv`：唯一手工维护源。按分组一行一本／一个套装。
- `catalog.json`：合并书目元数据后的完整结构化数据，适合程序或 Agent 查询。
- `catalog.jsonl`：一行一条，适合按书名、主题、场景快速检索。
- `browse/*.md`：分组浏览卡片，适合人读，也适合伙伴按组加载。
- `index.md`：147 条紧凑目录，先在这里定位，再打开对应分组。
- `../../schemas/book-knowledge.schema.json`：数据结构定义。

## 检索协议（给伙伴）

1. **先回应孩子当前的事情**，不要为了用书库而转移话题。
2. 在 `index.md` 或 `catalog.jsonl` 里按 `book_id`、书名、`topics`、`use_when` 找 1–2 个候选；一次最多递一本。
3. 打开完整记录，只使用：
   - `gist`：确认不要讲错大意；
   - `child_bridge`：在非作业场景、孩子的话题接得上时使用；
   - `use_when`：判断时机；
   - `talk_angles`：孩子愿意聊时再选一个；
   - `guardrail`：剧透、年龄、题材和不确定性边界。
4. **B 级**可以讲公认大意与著名公开桥段，但不能编具体页码、具体原文句子或“我重读过”的经历；**C 级**只介绍主题，孩子追问具体情节时如实说“不确定，可以一起翻一页”。
5. 作业期间不调用本库；普通聊天不自动转荐书。
6. 孩子不接、说没兴趣，就是完整选择。不追问、不安排阅读任务、不记录“未完成”。

## 字段说明

| 字段 | 用法 |
| --- | --- |
| `entry_type` | `single` 单本；`series` 系列；`collection` 合集；`magazine` 杂志；`workbook` 教辅；`unknown` 待核 |
| `audience` | 主使用对象；不等于阅读能力测评 |
| `age_hint` | 粗略年龄建议，不是门槛，也不是孩子当前水平 |
| `use_modes` | `child_read` 孩子可自读；`co_read` 共读；`discuss` 可转化聊天；`background` 伙伴背景；`parent_only` 家长自读；`lookup` 查询工具 |
| `topics` | 用于检索的主题标签 |
| `gist` | 可转述的内容大意；合集只描述共同主题 |
| `child_bridge` | 一条可以自然说出口的入口；没有就保持空白 |
| `use_when` | 什么场景值得取用 |
| `talk_angles` | 孩子愿意继续聊时的方向 |
| `guardrail` | 剧透、争议、暴力、死亡、版本或不确定性提醒 |
| `source_grade` | B：公开书目/既有稳定知识；C：仅目录/书名/家长备注 |
| `source_note` | 本次能确认到什么程度 |
| `related_ids` | 同一系列、作者、主题或重复登记关系 |

## 来源纪律

- 本库没有 A 级：本次没有逐页重读这 147 条；不要声称“我读过这本”。
- B 级也不是逐页核对。讲大意可以，页码、原句、章节、具体情节顺序一律不编。
- C 级不要主动讲情节；先看实体书、目录或可靠书目资料。
- `catalog_note` 只是书架识别备注，不是内容事实；`status`、`owner`、`transition_level` 不进入本库。
- 同一条目可能是系列、合集或重复登记，数量要按 `entry_type` 说清楚，不能把 147 条说成 147 本独立单书。

## 维护

编辑 `data/*.tsv` 后运行：

```bash
python3 library/book-knowledge/build.py
```

构建会检查：147 个 `book_id` 完整且唯一、字段非空、来源等级合法，并重新生成索引和浏览文件。
