- `bookshelf.json` — 家庭书目库，格式见 `schemas/bookshelf.schema.json`。
  - `bk-0001 ~ bk-0039`：孩子书架 39 条，2026-10-26 由 8 张实拍识别建立，家长文字补充（神奇校车、好奇号、少年新知、商界少年、DK 系列、2001 太空漫游）。

- `parent-materials/` — 家长上传的书籍/课程原文（刘擎《西方现代思想讲义》等）。**已 gitignore，版权内容不入库。**
- `notes/` — 家长素材的提炼要点（伙伴可用的"思想对话卡片"），入库，只含转述与观点摘要。

## 家长维护方式（唯一需要做的）

收到书后把对应条目 `status` 从 `wants` 改为 `unread`（已在架上）即可；其余字段由伙伴在使用中更新。
