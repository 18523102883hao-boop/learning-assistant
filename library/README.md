- `bookshelf.json` — 家庭书目库，格式见 `schemas/bookshelf.schema.json`。2026-10-26 由书架实拍 8 张照片识别建立（39 条），家长文字补充（神奇校车、好奇号、少年新知、商界少年、DK 系列、2001 太空漫游）。

## 家长维护方式（唯一需要做的）

收到书后把对应条目 `status` 从 `wants` 改为 `unread`（已在架上）即可；其余字段由伙伴在使用中更新。
