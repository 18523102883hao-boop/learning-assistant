## 联动用法

书目知识库是"这本书是什么"的事实底座，引读卡片是"怎么开口"的话术，思想卡片是"把对话垫高"的骨头。聊某本书时先用 `book-knowledge` 核对大意和边界，再取一句引读话术，必要时用思想卡片加深（例：聊《明朝那些事儿》垫 lq41"冲突中汇聚"；聊《神奇校车》垫 lq03 祛魅；孩子集卡/抽盲盒时垫 lq27 虚假的需求）。B/C 级卡不等于逐页精读，不编页码、原句或"我读过"的经历。
