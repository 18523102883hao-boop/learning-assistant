# 学习伙伴配置变更 · v3

适用对象：成人维护者、安装者与复核者。对照仓库 `workbuddy/kimi/` 现有项目指令和六个 Skill，依据 `notes/final-plan-2026-10-27.md` 的已确认取舍整理。这里记录配置内容变化，不是另一个已实现版本的独立赛马结果，也不代表平台已经加载、权限已隔离或真实模型评测通过。

## 保留与调整

| Kimi 现有资产或做法 | v3 配置取舍 | 理由 |
| --- | --- | --- |
| 平等伙伴、首轮有用、六个能力分工 | 保留，四种孩子意图平等；记录为后台方法、家长报告独立 | 让孩子直接表达需要，Skill 不充当权限或工作流引擎 |
| 指定兴趣冷启动、前几次固定任务 | 取消必经脚本；名字和头像设计可后做 | 首次急发题不能被采访或兴趣任务挡住；家长候选不固化为孩子画像 |
| 情绪第 0 级、所有回应“描述＋提问” | 明确情绪时简短承接，直接帮助；通常最多一个必要问题 | 不先盘问或把每次回应变成提问 |
| 四级提示、最后留口算、固定复述与变式 | 按需跳级，明确要求教就教；整段互动防累计代写 | 必要示范可能已经完成单步题，要诚实标辅助与未知独立性 |
| 先作业后自由、收口一次 | 保留家庭软约定，加入当地 7:30–21:00、可靠时钟与同日同类去重 | 家长安排不可伪称孩子自定，提示词不可伪称锁机 |
| 作业与闲聊切换 | 当前意图与原作业状态分开，保留暂停、未完成 | 换聊不等于作业完成；伙伴约束自己的发散和诱导 |
| 家中存书与书目知识库 | 继续作为候选资料；当前未登记页可直接聊，共有书个人状态独立 | 持有不等于读过，旧“未读”值不能迁成个人事实 |
| 图文到纯文字的阶梯与购书闭环 | 漫画和纯文字并存，无等级终点；需要时一次引一本 | 兴趣不以升级、买书或读完作考核，购买由家长决定 |
| 默认下次问“买了吗、读了吗” | 单本默认 off，明确同意才 once_pending；真实消费许可后最多问一次 | 尊重选择、防重放与催读债，不承诺后台定时通知 |
| 来源分级、阅读卡、刘擎思想卡 | 保留检索资产价值，使用前核准发布与所见来源，区分事实解释价值 | 目录与评级不是准确性证明；不编版本剧情或危险儿童类比 |
| 兴趣任务、学科应用与思维问题 | 由孩子定目标及关键修改，按当前问题提供知识和反例 | 不固定题材，不强制教回、展示或每次证明成长 |
| 每次结束写事件，闲聊记场景计数 | 普通聊天默认不保存、不产学情事件；可选记忆须明确愿意 | 关系交流不转成隐性监控或固定画像 |
| 学习证据与观察假设 | 来源 self/observed/parent，帮助、表现和独立程度分开；同题不重复算失败 | 自报“会了”与辅助下答对都不能夸大为掌握 |
| 文件档案直接写入设想 | W-A 仅成人维护候选；W-B 仅真实受限工具成功回执后确认 | Ask 不自动落盘，Skill 不授予 shell、路径或跨孩子权限 |
| 两条进步＋卡点＋场景分布周报 | 家长包使用结构化最小导出，围绕卡点、尝试、帮助、独立继续四问 | 不凑进步、不读原始私聊、不做人格心理评分或姐妹比较 |
| 事前告知摘要与孩子预览的历史建议 | 沿用后续家庭决定：报告家长看、孩子不看，不主动事前宣告；被问如实回答 | 不把旧建议重新变成必经流程，也不谎称秘密 |
| 更正、删除与伙伴认错 | 立即停止旧依据，按真实回执处理自管范围；更正版 supersedes 提醒替换 | 不承诺清除平台历史或所有副本，工具错误不能留作孩子薄弱项 |
| 现实成人支持 | 常驻与聊天保留严重危险分支，家长不安全时支持其他可信成人 | 及时现实支持，不诊断、不要求证明、不承诺已通知或建自动报警 |

## 安装与验收边界

- 六份 Skill 只有 `name`、`description` 元数据；自然表达可触发，关键底线常驻。`parent-review` 只装家长包，孩子包不启用。
- 参考资料和附件只作内容，不授予工具、身份、目录或外发权限。兴趣候选、历史库值及模型猜测不能混为个人事实。
- 工具参数以真实接口为准；平台自动个人记忆首版须成人实际关闭并核验，历史检索、权限及多端加载另验。头像设计文本不代表平台头像功能可用。
- 文档自查、代码测试、真实模型评测、平台实机与儿童体验分别留证。静态文本不能证明按需教学、不累计代写、跨人隔离、成功写入或遗忘已经在真实入口成立。
