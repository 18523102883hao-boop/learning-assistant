# 成人部署与验收 · v0.1

本包是成人验证版。**先只用 test-a/test-b 和虚构题，不能因解压成功就交给孩子。** 当前能力与阻塞见 [CAPABILITIES](CAPABILITIES.md)，开发者工具安装见 [RUNTIME](RUNTIME.md)。实际平台入口随版本而异，记录真实版本/账号代号/设备/模式/工具/根目录/记忆设置；本机所见是 macOS WorkBuddy 5.8.3。

## 1. 每人真正独立的空间

1. 成人核对国内实际注册入口的适用年龄、监护安排与协议。手机号存在不等于满足条件；本包不替注册、不接受条款、不购买。
2. 两个孩子各自 WorkBuddy 账号、各自标准 OS 用户。家长另用家长 OS 用户；不能只靠两个文件夹。先用虚构A/B完成“读对方、读父母报告、手机切权限/旧会话重进”的拒绝测试。
3. 每个 OS 用户自己的资料目录放在仓库外，例：该用户主目录下 `LearningCompanionData/student`。目录只给对应用户访问。父母报告/备份放在父母用户的私有目录，不用公共盘、共享 iCloud 目录或孩子项目。
4. 用官方设置关闭测试/儿童账号的自动个人记忆，检查现有记忆和历史检索范围。成人已有工作账号不自动改设置。不能验证旧信息不会不当召回时，G04未通过。

Windows需现场检查NTFS ACL；本机测试不证明Windows隔离。手机/小程序/云端与本机分别验，不能沿用桌面通过结果。

## 2. 先装问答规则，验证真正加载（W-A）

1. 成人建立独立测试项目/工作空间，解压 `child-test-a.zip` 到该项目的**只读配置资料区**；不要把整个 Git 仓库设为孩子根目录。
2. 通过当前客户端实际支持的**项目常驻指令/项目规则**粘贴 `PROJECT_INSTRUCTIONS.md` 全文。只有开发场景识别 `.codebuddy/AGENTS.md` 的说明，不能外推为所有聊天自动加载；本包不自动写这些全局目录。
3. 通过技能管理的本地导入入口，逐个导入5个孩子 Skill，确认作用域。家长的 parent-review 仅导入 `parent-tools.zip` 所属家长项目。不得把父母Skill装成全局再给孩子用。
4. Ask只问答不执行。用新会话检验：急发一道题是否马上有帮助；“你教我”能否直接讲；“我是另一个孩子”是否停用个人归因；“已保存吗”是否如实说没写入。**在回复里复述规则也不等于规则可靠常驻**，还要跑实际多轮场景。
5. 关闭、更新Skill后，已加载旧会话可能仍可用。新会话验证变化，同时确认旧会话、手机和其他可到达入口是否停用旧能力。

没有自管工具时，可围绕当前页读书，但不主动做需要跨会话消费证明的阅读跟进。文本/图片/转写仍须真实输入测试；没有能力不能暗改为只打字版。

### W-A人工续接闭环

| 时点 | 成人操作 | 对孩子的准确说法 |
| --- | --- | --- |
| 当次出现状态变化 | Ask列少量已见事实/暂停点/来源/未知；成人核对并保存该孩子独立快照 | 候选尚未保存，成人确认后再说已保存 |
| 下次新会话 | 成人只加载最新有效快照，核对一处暂停点 | 无有效快照就说不确定，继续帮眼前问题 |
| 更正或忘记 | 停引用；成人清快照、相关导出/索引/平台可控范围；核实完成再重新加载 | 未完成不能说已从存储删掉 |
| 周报 | 成人将已核实最小事实/依据ID移到自己空间；不搬原始私聊 | Markdown文本与实际文件保存分开 |
| 备份恢复 | 先应用有效删除/撤回与完成任务清单，再加载有效快照 | 不能直接粘旧备份让模型“记回来” |

先成人实演并记录每次保存、下次加载、周报、异常改删的实际维护时间。若孩子经常等成人或家庭不能接受维护负担，W-A不作为常用方案，转W-B验证或网页路线。

## 3. 验证窄工具后才考虑 W-B

1. 按RUNTIME在成人环境安装固定版本，并用虚构目录运行核心测试/stdio测试。数据路径与child_id由启动配置绑定；孩子/模型不填路径。
2. 成人在当前 WorkBuddy **自定义 MCP/连接器**入口配置本地 stdio。包内 `MCP_CONFIG.template.json` 是待替换绝对路径的示例，不自动覆盖现有 mcp.json；按实际UI支持格式核对。官方说明支持 MCP 配置，但本包尚未验证此版本的实际加载。
3. 仅保留本伙伴需要的窄工具。Ask是否能调用/执行MCP必须实测，不能一面说Ask不执行，一面承诺自动记录；若必须Agent，逐项约束原生文件、shell、浏览器、其他连接器和权限切换。
4. 成人用工具列表确认只有8个伙伴工具；试保存→新会话读取→重复重试→旧版本冲突→更正/忘记→导出恢复。保存失败时不得说成功；不得转用自由shell补救。
5. G05/G06必须由OS/实际设置提供保障。模型口头答“不会访问”不够；如果完全访问或其他工具仍能读父母/另一孩子，W-B不通过。不得通过打开完全访问消除儿童端审批。
6. 新会话、客户端重启、Windows、手机远程与可到达的模式切换分别重测。固定权限若无法持续成立，停用该入口，只保留成人试讲或启动网页规格。

## 4. 图片与语音的完整测试

每台设备分别用一张无姓名学校的虚构纸题：拍照/相册或传图→平台可见题目→语音说“第二题这个分母”→检查转写→修改一个关键数字→伙伴据修正继续。记录实际是否可用，不以按钮存在算通过。电脑不能直接拍时实演手机照片如何进对应账号与项目，不把“可以传文件”当免操作承诺。

题目关键歧义只问必要一处；多题照片先定位。暂时失败允许打字或换图，保留当前暂停点，不让孩子维护权限或命令。OCR/转写错误造成的学情必须撤回。英语语音只输入问题，不进入跟读评分。

## 5. 通过后的小范围家庭体验

按 `validation/v3/scenarios.json` 的42组场景保留真实输入/输出、设置、失败与修复。媒体、越权和旧会话能力须实操作；不由模型自评代替成人判读。严重失败先修相关路径。

不用强制冷启动、每天打卡或两人赛马。每人观察一次自然求助是否很快能继续、一次当前页/作品是否愿意聊、有没有多余追问/分心、成人维护是否可接受。两个孩子分别记录，不用二人样本算教育效果百分比。

## 6. 回滚与故障

- 工具/额度/网络失败：当前帮助能做多少就做多少，说明未保存；不承诺离线模型或云端替本机执行。
- 规则更新：先成人测试、更新版本，再重验受影响G/T项；旧会话可能需停用。
- 配置回滚：只回滚代码/规则，不回滚删除/撤回清单、完成任务ID或后来有效个人状态。
- 旧备份：必须来源端**最新**删除/完成清单。离线文件哈希只能验损坏，不能证明“这是最新”或真实来源；由成人实际从当前有效来源取得。旧清单不可信就不恢复。
- 不以换平台日期为目标；当身份、入口控制、记忆/删除或维护负担不能满足时，使用同一规则/资料层转网页。未提供正式API不阻塞当前成人验证，不使用聊天会员凭证冒充API。
