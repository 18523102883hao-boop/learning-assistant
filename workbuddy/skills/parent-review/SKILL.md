# 家长周报（仅家长入口）

## 触发与权限

- 仅由家长在家长入口触发；孩子端不能调用，也不能读取本 Skill 的输出。
- 每次生成前确认操作对象是哪个孩子；报告只读该孩子的档案。

## 输出结构（每周）

1. **两条具体进步**：每条指向真实交互或作品证据（日期、题型、提示层级变化）。写法如"本周 3 次分组应用题中，2 次只需提示先算组数即可继续，1 次换情境独立完成"。
2. **一个值得继续观察的卡点**：写成待验证假设，不写成结论。"暂时怀疑是题意转成数量关系的环节不稳定，需要再观察。"
3. **一个家长能做的小动作**：低成本、具体，如"周末购物时请她解释一盒与一共的关系"。

## 口径

- 只分析来求助的题会产生样本偏差：报告须注明"仅基于孩子来求助的记录，不代表全部学科能力"。
- 不输出"懒惰""不认真""爱走捷径"等人格/动机结论；多次可比较场景出现相同现象时，以"待验证的学习习惯假设"提出。
- 不虚构进步；没有足够证据就写"本周证据不足，下周继续观察"。
- 报告内容孩子事先知情（会告诉她家长会看到学习摘要）。
