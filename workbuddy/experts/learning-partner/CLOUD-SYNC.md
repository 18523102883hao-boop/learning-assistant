# 沫沫云端同步与验收 · v1.2.0

对应分支 `experts/learning-partner-momo`，包路径 `workbuddy/experts/learning-partner/`，槽位 student-a。只用于沫沫账号，不能和另一个孩子混装。GitHub上传与云端配置更新是两步；只改家中Mac文件夹不生效于云上。

## 家长操作顺序

1. 登录沫沫的WorkBuddy账号，确认任务运行位置为“云上/云端电脑”；在该账号选一个单独私有云项目。不要把姐妹或成人工作账号加入同一项目。当前入口若不提供项目，先用该账号私有云资料库与专家入口做同等验收，不声称项目功能已存在。
2. 在成人维护任务中给下面提示。已有官方GitHub连接可从指定分支读取；私有仓库无权限时由家长在官方界面授权，或直接上传对应分发ZIP。不要在聊天发送GitHub token。
3. 在云项目配置中实际选择/更新本专家与六个Skill，云上个人库/项目库必须看得到；本地安装列表不算。将 cloud/云端项目指令.md 放项目指令；cloud/云端资料合辑.md 上传并关联项目资料库。项目资料的RAG/文件读取须实测。
4. 仅首次由 cloud/伙伴档案-空白模板.md 建立该账号自己的持续档案。以后更新专家只更新规则/只读资料，不能拿空白模板覆盖已有档案。文件不回传GitHub。
5. 在设置→记忆检查真实状态。可用 cloud/初始记忆-仅本账号.md 作为一次导入线索；这是父亲提供的起始信息，不代表孩子确认全部兴趣。不需要孩子背口令或填档案。
6. 家中电脑关闭后，按下方成人云验收验证。读取不到资料、不能持久修改档案或记忆未生成，都如实报告具体缺口，不用完全访问权限补缺口。

## 验收后再给孩子自然使用

- 查资料：真实读取 bk-0017 的公开介绍来源；知道147条是目录，不说已读147本。找到 specific-listening 和其课程来源ID，不把113项索引当全文。
- 断开本机：关家里电脑后重复上一步，排除偷用了本机路径/服务。
- 档案：由成人用虚构事实测试实际更新、读回版本、在新云任务读取；只生成一份任务产物不算。测试更正和删除并新任务再读。不要把合成“蓝星号”等留为孩子真实经历。
- 原生记忆：等待平台真实整理后新任务召回，设置更正/删除后复验；不能用当前上下文或文档读回冒充原生记忆验证。
- 隔离：另一账号不能查到本账号合成事实/档案；不同项目都在同一账号时不等于个人记忆隔离。
- 体验：作业急求助先给有用一步，闲聊自然不强转学习，拒记先停引用且诚实说明范围；不能每次都说“我没工具什么都记不住”。
