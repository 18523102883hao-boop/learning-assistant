# 沫沫云端更新与验收 · v1.3.0

适用learning-partner / student-a，只在沫沫专用账号维护。发布说明提供固定提交和ZIP SHA256，不能从main或滚动分支猜最新。下面是家长维护流程，不能让孩子维护文件或权限。GitHub读取和专家云安装是两件事。

## 1. 取得正确且固定的包

家长登录本账号，确认使用云端电脑，在“我的专家”的本专家维护/修改入口发起任务（菜单名称以实际版本为准）。先读发行说明里的本账号固定提交、CLOUD-RELEASE.json、cloud/update-policy.json和CHANGELOG.md。仓库内目录均是workbuddy/experts/learning-partner/，但内部包名不同，不能凭目录名判断。读取私有资源若需要授权，只在官方界面由家长处理，不发密钥。

从固定commit读取全部该目录文件，逐个核对CLOUD-RELEASE.json中的SHA256；或下载发行页上本账号ZIP，先核对发行说明中的整包SHA256，再核对包内全部文件。没有核验能力就报告artifact_verified=not_verified，不伪称通过。校验manifest本身依赖固定commit或发行说明中的整包SHA，而非自证真实性。ZIP读取/解压只表示取到资料。

## 2. 先确认已安装对象，再改规则

核对本账号实际已装专家的包名、版本与编辑对象。如果现有名称不同（例如孩子自选名字），先核对其确为本账号原伙伴，保留显示名和孩子选择的人格偏好；来源包名learning-partner不得装到另一个孩子槽位。不要删除重建专家来代替普通更新。没有当前已装对象读回，就不能报告expert_updated=passed。

有平台实际提供的专家修改能力才更新agent与六个Skills；否则明确请家长到哪个当前可见入口完成。不要把写~/.workbuddy、云沙箱插件目录或临时任务文件说成更新了账号专家。不安装本机MCP，不变更全局记忆、授权或其他专家。

## 3. 云上关联与个人资料保护

更新本账号私有云项目指令为cloud/云端项目指令.md，更新/关联只读cloud/云端资料合辑.md。若平台当前无项目入口，按真实的私有云资料库/专家关联能力验证，不编造功能。云上应可选六个Skill：homework-help、reading-companion、explore-task、partner-chat、learning-log、companion-knowledge；本机列表不算。

已有伙伴档案、原生记忆、阅读状态、私人课程资料、账号授权均保留；不能覆盖或回传GitHub。cloud/伙伴档案-空白模板.md仅首次且确实没有档案才创建；升级不重导cloud/初始记忆-仅本账号.md，不从旧档案/备份复活被撤回内容。格式兼容companion-cloud/1，新字段按需使用，不做批量迁移。规则备份只保留上一版规则/只读资料；涉及真实个人内容仍留本账号私有位置，不生成儿童私聊备份上传仓库。

## 4. 分步回执，未知保持未知

可用cloud/更新回执-空白模板.json作为成人维护结果格式，不上传真实账号或私聊。六阶段各写passed/failed/not_verified、实际证据位置与缺口：

1. github_readable：读到了指定固定commit及本账号包。
2. artifact_verified：整包/逐文件校验及包名、槽位、版本一致。
3. expert_updated：平台真实专家对象已更新并读回版本/内容；仅生成文件不算。
4. cloud_skills_visible：云配置确有六Skill且可读取对应参考素材；列出实际看到的对象。
5. library_linked：真实检索/读取bk-0017、specific-listening、g5-decimal-place及来源边界；能读合辑不等于全书/全文课程已提供。
6. new_task_verified：在新建云任务中仍读取到v1.3.0、原有档案保持、当前卡点与非作业陪伴场景实际运行；记忆/媒体另按TESTING.md标明结果。

不得靠模型自述“加载成功”补状态。平台不能完成的步骤报实际界面入口和待家长动作；失败保留可用旧规则/资料，若部分已更新写清，不承诺平台未提供的原子回退。回退只用cloud/update-policy.json记录的上一版固定来源，并仅恢复规则/只读资料，不覆盖个人资料。

## 5. 家长新任务验收

先跑TESTING.md和仓库validation/cloud-v1.3/优先八组，再按需要检查42组基线。用合成事实且不要将其作为真实孩子经历保存；若实际测试了持久化，结束后按真实能力清除并新任务确认。照片/语音、记忆更正/拒记/删除、账号隔离必须真实云验证。单元测试和校验包不能证明这些已通过。确认云模式在不连接家中电脑条件下可工作，云任务无需Mac路径。

新版是可供成人安装试用的固定分发，不是已替两个真实账号完成云验收。不能承诺GitHub一推送两账号自动升级。
