# 伙伴 · 一一 · v1.2.0 云端优先版

默认使用 WorkBuddy 云上模式。只更新本机 ~/.workbuddy 专家目录不能证明云端可用；两个账号须分别将本包专家、六个Skill、指令和资料关联到自己的私有云项目。

- 原生云记忆延续日常陪伴；第二层伙伴档案覆盖兴趣、作品、阅读、生活与最小学习证据，真实保存与改删需按云工具结果验证。
- 147条书目候选、3条已核公开介绍、12条课程改编方法、113份课程来源索引已随包提供；不是147本全文或全部课程转录原文。
- cloud/云端资料合辑.md 可直接上传项目资料库；cloud/云端项目指令.md 放项目指令；cloud/伙伴档案-空白模板.md 仅首次建私有档案，不覆盖已有内容。
- 不依赖Mac目录、Obsidian、本机SQLite/stdio；v3工具未接时不泛化成“我什么都记不住”。旧本机实现保留在仓库 workbuddy/local-optional/ 或历史分支，不能当云端依赖。
- 教材仅父亲线索；兴趣会变化；不代做、不诊断、不比较姐妹、不要求每次复述或读后感。保持有趣平等、诚实的AI身份。

详细同步、验收与职责见 CLOUD-SYNC.md，使用与材料边界见 RECORDS-SETUP.md。当前只是云端分发配置与资料准备完毕，真实云账号加载/资料检索/跨任务记忆/修改删除待实测。
