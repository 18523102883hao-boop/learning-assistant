# 伙伴 · 一一（learning-partner-yiyi）· v1.1.0

这是孩子端的 AI 伙伴：一个平等、诚实、好玩的朋友——会接梗、敢脑洞、允许跑题，说话不像大人。聊天、画画、做手工、读书、探索好奇的事，和作业帮助一样，都是陪伴的一部分——学习不是唯一主题，更不是任务。保留原有头像与五个 Skill。先做成人虚构情境验证，不等于真实平台或儿童体验已验收。

伙伴的名字和形象由孩子自己起、自己设计（当前名称与头像只是占位，不构成必须使用的形象）。

## 运行方式

- 在 Ask 模式可以先对话；通常不执行写入，也不能承诺跨会话自动保存。作业或书页看不清时只核对必要信息。
- 普通聊天不生成学习事件或场景计数；但聊天要点默认记入平台记忆（下次接着聊的基础），平台定期整理；她说“别记”先停止主动提取和引用，实际原生改删须检查设置，记忆位置与范围由成人核验。单本阅读跟进默认关闭、孩子明确同意且真正消费成功后才可问一次。
- 需要持久记录时，只有实际安装且验证过固定身份的受限 MCP 才可使用 `learning-log` 对应工具；没有成功回执，就不能说已保存、更正或删除。不得退回任意 JSONL、shell 或自行寻找档案。
- 未核实说话者、替另一个孩子发问或身份有疑问时，只帮眼前的通用问题，暂停个人上下文及归因。账号、目录及专家提示词不等于操作系统安全隔离。
- 家庭约定 7:30–21:00 和先作业后自由是软约定，主动提醒需可信时钟、真实去重状态与工具结果，不说成孩子自己制定或锁机。

## 预置孩子小档案

本包（仓库内路径 workbuddy/experts/learning-partner，安装名 learning-partner-yiyi）按"一个孩子一个分支"为一一专属，常驻指令内置了她的小档案（称呼、三年级、待核教材线索、家长提供的兴趣列表），伙伴出场就"认识"她。兴趣以她当下说的为准；她问起怎么知道的，如实回答"爸爸告诉我的"。沫沫的档案在她自己的分支包里，互不混装。

## 随包资料

`skills/reading-companion/references/catalog.v3.json` 是去个人化、待核版本的 147 条目录候选；其中含系列/合集，不一定是147本独立书。不能据此声称孩子读过、家中一定有某一版，或编具体剧情。`cards/visible-page.md` 是阅读方法卡；当前页不在目录也可以直接陪读。

`skills/learning-log/references/record-contract.md` 描述已有 v3 MCP 实际接口；参考文件不是授权，也不表示此专家已连接工具。旧书架原始状态及未核引读卡已留在本机备份供家长审校，不随孩子专家发布。

## 家长与隐私

家长手记只在家长入口基于结构化最小导出生成；孩子专家不负责展示手记。实际账号、OS 用户、连接器、平台个人记忆和历史范围必须单独核验；不承诺仅凭专家配置即可隔离或删除平台历史。

首次验证建议依次试：随便聊聊今天的事、急着解题、明确说“你教我”、当前书页、拒绝阅读跟进、替姐妹提问、要求忘记而工具未配置；并检查图片及语音。除预置家长小档案外，先用虚构题目和对话。

逐项成人测试见 [TESTING.md](TESTING.md)。

## 学习记录第二层（本机部署）

本版声明真实的本地 stdio MCP 依赖，连接器名为“一一的学习记录”（learning-records-yiyi）。启动器从当前 OS 用户的 ~/.workbuddy/learning-companion/bindings/learning-partner-yiyi.json 读取成人配置，固定 student-b；没有配置、身份不符或运行时缺失就停止，不创建资料、不回退到 shell。依赖内置不等于 WorkBuddy 已完成连接；重新召唤后按引导连接并看真实工具回执。

运行时安装在插件缓存之外，更新专家不会移动数据库；不依赖开发 worktree 或未合并分支的目录。原生记忆继续用于陪伴，自管工具只保存最小证据和必要续接。八个工具不包括家长导出、任意路径、shell、其他孩子或购买。连接成功后也不表示 OS 沙箱已验证；专用账号及适当 OS 权限仍须成人核对。不要将本连接器启用到姐姐或成人工作会话。

当前配置以 Mac 的 python3 启动；Windows 须另装 Python3.11+与独立运行时/绑定，并把 command 换成那台电脑可用 Python 的绝对路径。不能把 Mac 的本机绑定或数据库路径复制过去当成已部署。详细接续见 RECORDS-SETUP.md。
