# 学情周报

## 输入

一个孩子的学习事件文件（jsonl），日期范围。字段定义见孩子端 `learning-log` 的 schema。

最低可用字段：`event_id`、`timestamp`、`scene_type`、`subject`、`attempt_summary`、`assistance`、`performance`、`independence_evidence`、`outcome`、`source`。

## 生成规则

1. **先算样本**：这周一共几条事件、覆盖哪几个场景（作业/探索/共读/闲聊）、哪几天。**样本说明必须写在最前面**，因为只记录"来求助的题"必然有偏差。
2. **按四问组织**，不按学科罗列：
   - 卡在哪
   - 试过什么
   - 什么帮助有效
   - 能否独立继续
3. **每条结论挂 `event_id`**，家长可回查。挂不上就不写。
4. **进步最多一条，宁缺不凑**。要具体到"哪次、什么题、在什么帮助下做到什么"。
5. **卡点写成待验证假设**，不写结论："暂时怀疑是题意转成数量关系这一步不稳，需要再观察。"
6. **家长动作只给一个**，低成本、不需要买教具、不制造新任务，且孩子可以拒绝。
7. **场景分布行**：作业 X 次 · 探索 X 次 · 共读 X 次 · 闲聊 X 次。只计次数，不展示内容。供你判断闲聊是否挤掉作业——如果连续两周明显挤占，在家庭产品会上调整安排，**不要在日常指责孩子**。
8. **工具错误单列**：识别错、讲错、保存失败、更正记录，全部单列一节。

## 语言

- 成人语气，陈述为主。不写"您一定要""加油""相信孩子"这类话。
- 不使用评价人、评价动机的词（完整禁词表见 agent 主文件红线 1）。
- 不出现同学姓名、不出现聊天原话。
- 篇幅一屏半以内。

## 落盘

- 输出完整 Markdown 全文（不是只给摘要）。
- 文件名：`周报-{昵称}-{YYYY-MM-DD}.md`，日期用报告覆盖的最后一天。
- 保存位置由家长指定（Obsidian 库 / iCloud 目录 / 本地文件夹），**不进孩子目录、不进 Git 仓库**。
- 更正版：文件名加 `-v2`，正文顶部标 `替代：周报-…-{日期}.md`。

## 自查清单

- [ ] 样本说明在开头，且写明了偏差
- [ ] 四问都有，缺的部分写"证据不足"
- [ ] 每条结论都能追到 event_id
- [ ] 没有任何人格/动机/天赋词
- [ ] 没有姐妹对比
- [ ] 进步不超过一条，且具体
- [ ] 家长动作只有一个，孩子可以拒绝
- [ ] 没有聊天原话、没有同学姓名
