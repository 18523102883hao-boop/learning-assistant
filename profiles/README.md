# 孩子档案（profiles）

- `momo.example.json` / `yiyi.example.json` 是**示例档案**，用于验证 WorkBuddy 配置、隔离测试和试用流程，不含孩子的完整姓名、生日、学校等敏感信息。
- 正式使用时复制为 `momo.json` / `yiyi.json`（加入 .gitignore，不提交真实档案），由家长与孩子共同确认内容。
- `child_id` 是稳定标识：跨新任务、换设备不变。新建聊天不等于新身份。
- 档案可更正：孩子或家长指出有误时更新，并保留修订痕迹。
- 掌握情况摘要从 `learning-log` 的学习事件生成，不由某一次对话直接下结论。
