# 孩子档案与资料边界

本仓库只保留可公开复用的示例和说明；真实孩子档案、朋友姓名、学习记录、报告和备份应保存在仓库外的受限目录，不复制进专家包。历史分支或旧提交可能仍含此前上传的信息；删除新版本中的文件不会改写既有历史。

旧的 `current.json` / `kids.json` 人工切档和自由 JSONL 追加流程已停用：它不能证明真实说话者身份、OS 隔离、撤回清理或恢复安全。请勿因文件里有 `child_id` 就把聊天内容归给某个孩子。此前真实文件在本机保留，但不再作为本专家的自动身份发现依据。

需要持久资料时，由成人在各自的 OS 私有目录部署并验证固定绑定的 v3 受限工具；只有真实成功回执才说保存、更正或删除。没有工具或身份有疑问时继续通用对话，不进行个人归因或任意文件写入。

孩子与家长分别使用受限空间；账号、提示词和目录名本身不等于技术隔离。孩子更正/忘记时先停止引用，再按工具实际范围处理；平台历史、自动记忆及旧备份另需管理。教材版本未核实只按眼前问题做跨版本帮助。
