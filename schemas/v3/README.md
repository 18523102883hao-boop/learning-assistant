# v3数据合同

record.schema.json为JSON Schema 2020-12的外部形状合同。JSON记录版本3与SQLite物理格式4分别版本化；旧物理库明确拒绝，成人显式migrate后再用。旧备份或旧学习事件不自动补造独立掌握。

精确语义、跨记录关系、固定身份、版本冲突与来源核验以companion/contracts.py、store.py和[接口速查](../../workbuddy/final/skills/learning-log/references/record-contract.md)为准。JSON形状正确本身不证明当事人、孩子愿意、教材正确或平台授权。

source_kind、来源的实际接触范围、准确性与发布用途分开。self/observed/parent为概念口径，不是工具可提交枚举。完整辅助示范、孩子自报、当次无提示尝试和延迟迁移不混用。

恢复要求当前有效撤回与任务完成清单；离线哈希不证明最新或可信来源。运行资料在仓库和源码外；样例只用虚构身份。
