# v3 验证记录

这里严格分开软件验证、真实模型对话、平台/权限和儿童体验。软件通过不能把后面三项填成通过。

- `scenarios.json`：工程附录42组成人用例，初始均 `not_run`；保留真实输入/完整相关多轮输出/设置/实际判定后才能改变状态。
- `software-results.md`：本地命令与独立审查范围，包含未解决限制。
- `workbuddy-observations.md`：去标识的实际UI观察，不存账号ID、URL签名、工作历史截图或凭据。

每次真人操作或模型情境记录：case_id、当地日期、规则/材料/代码版本、模型名、平台版本、OS、账号测试代号、模式、工具/路径权限、记忆/历史设置、输入、实际输出、首次有用帮助的观察、判定及理由。失败和修复后结果均保留；不要让模型自评替代成人。

T10/T11的图片与转写、T32的历史召回、T33/T35的真实工具链、T36/T40的越权/旧会话/切换，需要实际操作。不拿文字假扮照片上传成功，也不以核心单元测试已覆盖一部分就把完整T项改成通过。

全部使用虚构小松/小禾与合成题。真实孩子、同伴、照片、聊天、报告不放此目录。儿童试用另在家长私有空间观察，不要求每天使用，不比较姐妹，不生成两样本教育效果百分比。
